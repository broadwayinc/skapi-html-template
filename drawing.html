Shared Drawing

Two users draw on one canvas. Every stroke is sent over a WebRTC data channel, straight from one browser to the other, and drawn on the other side as it happens. No video is involved: a stroke is a few numbers, so this costs almost no bandwidth and both sides can draw at once.

skapi.connectRTC() opens the connection with a data channel named drawing and no media, unless Voice is on, which adds the microphone. The callee gets an rtc:incoming message whose meta says it is a drawing invitation.

Users find each other in the realtime group RTCDraw. Open this page in another browser or device with a different account and invite each other.
